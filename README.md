## About This Repository

I created this repository to hold my SDC320L course project. I'll be building it a piece at a time over the term and submitting the final version here. The project will cover the main ideas from the course:

- Reusing code with inheritance and composition
- Polymorphism and interfaces
- Abstract and concrete classes, constructors, and access modifiers
- Reading and writing objects with sequential files and a database
- Getting a working application ready to deliver
